## Fixed

Closing the app could leave the farewell animation on screen with the window
never going away, and no way out but ending the process by hand. It happened
when something in the shutdown work stalled — most often the final sync, on a
machine whose connection had quietly gone.

That work is now given a few seconds and then let go of. The window closes
either way. What is skipped is a sync that was already failing, and it will run
again next time you open the app; nothing you wrote is lost.
