## Lists

Nested lists read as a tree now. A rule runs down the left of each branch, so
the third level is as easy to place as the first, and a control beside the
marker folds a branch shut once you are done with it.

**Checkboxes work from the rendered side.** Press one in the preview and it
ticks — the note is edited for you, exactly as if you had gone back to the
source and changed the `[ ]` by hand. Finished tasks fade and strike through,
so a list you have been working down shows its own progress.

Ticking a box does not move the caret. You can be writing somewhere else,
press a box, and carry on from the same character.

## Fixed

Pressing a toolbar button — bold, a heading, a checklist — left the focus on
the button rather than the text, so Cmd/Ctrl+Z did nothing until you clicked
back into the editor. Undo now works straight after an insert, which is when
you are most likely to want it.
