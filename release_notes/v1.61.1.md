## Fix: the app could fail to open after updating

The previous build (1.61.0) could get stuck on a black screen for anyone updating from an older version — the database update it ran on first launch could fail partway through, so the app never finished opening.

This release fixes that update so it always completes. If you were affected, updating to this version resolves it — nothing you did was lost, and there is nothing you need to do by hand.
