## Tasks

Reminders are now tasks, and they carry everything a piece of work needs.

A task has a **status** — To Do, Doing, Blocked, Done — and a **Kanban board** to move it through them, alongside the flat list you already had. Give it a **project**, a **date**, or no date at all: an undated task lands in the backlog instead of pretending it is due today.

**Track time against a task.** Start the timer from the task itself and it moves to Doing on its own; the card shows the clock running, and the total across every session is on the task. From the timer, a tracked session opens the task it belongs to.

**Attach as many notes as a task needs.** Create one from the task and it is linked automatically, or link notes you already wrote. Read and edit them without leaving the task — rendered, not raw Markdown — and file them into a folder from the same place.

Every reminder you already had is now a task, with its history intact. Nothing to migrate by hand.

## Keyboard shortcuts

Jump to any section with **Cmd/Ctrl+1** through **9**, create a note or a task, focus search. **Cmd/Ctrl+/** lists them all, and Settings has the same list for when you would rather look it up than remember it. Hover any control that has a shortcut and it tells you.

Cmd on macOS, Ctrl on Windows and Linux.

## Fixed

Everything above briefly shipped as 1.61.0, which was pulled: on the first launch after updating, it could fail partway through preparing your data and leave the app stuck on a black screen. This release fixes that, and it is the version to update to. If 1.61.0 left you stuck, updating resolves it — nothing you had was lost, and there is nothing to repair by hand.
